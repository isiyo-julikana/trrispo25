# trrispo25

Сравнение уровней сжатия zstd — консольная утилита на C11.

- **Вариант:** 25
- **Программа:** сравнение уровней сжатия
- **Обязательные функции:** сжатие `zstd` с заданным уровнем; таблица «уровень — размер — время»
- **Библиотека:** `libzstd-dev` (runtime — `libzstd1`)
- **Дисциплина:** Технологии распространения, развертывания и сопровождения программного обеспечения
- **Текущая версия:** см. файл [`VERSION`](VERSION) (на ПР 1 — `0.1.0`)

## Назначение

Программа `trrispo25` сжимает файл алгоритмом zstd на заданном уровне и умеет
строить таблицу «уровень — размер — время», чтобы сравнить, как разные уровни
сжатия влияют на итоговый размер и на затраченное время.

Поддерживаются две подкоманды:

- `compress` — сжать файл на заданном уровне;
- `benchmark` — сжать файл на каждом уровне от 1 до N и напечатать таблицу
  «уровень — размер — время».

Уровень сжатия по умолчанию читается из конфигурационного файла
`/etc/trrispo25/trrispo25.conf`; ключ `--level` на командной строке имеет
приоритет над конфигом. Отсутствие файла конфигурации не является ошибкой.

## Требования

- Ubuntu 24.04 LTS (или Debian) — нативная система, виртуальная машина или WSL 2;
- GCC, CMake ≥ 3.20, `pkgconf`, заголовки `libzstd-dev`.

Полный список пакетов, нужных для сборки, хранится в одном месте —
файле [`build-deps.txt`](build-deps.txt). Установить их одной командой:

```bash
sudo apt update
sudo xargs -a build-deps.txt apt install -y
```

## Сборка

Из корня репозитория:

```bash
cmake -S . -B build
cmake --build build
```

Готовый бинарник — `build/trrispo25`. Номер версии берётся из файла `VERSION`
и попадает в программу через CMake (макрос `APP_VERSION`), а не записывается
в исходный код.

Проверка:

```bash
./build/trrispo25 --version
# trrispo25 0.1.0

./build/trrispo25 --help
```

Сборка проходит без предупреждений компилятора при флагах
`-Wall -Wextra -Wpedantic`.

## Сборка deb-пакета

Пакет собирается одной командой из чистого клона репозитория:

```bash
./build_deb.sh
```

Скрипт:

1. читает версию из `VERSION`;
2. определяет архитектуру через `dpkg --print-architecture`;
3. собирает программу с флагами усиления защиты из `dpkg-buildflags`;
4. устанавливает файлы по иерархии ФС через `cmake --install` (с `--strip`);
5. формирует поле `Depends` утилитой `dpkg-shlibdeps` по фактически
   слинкованным библиотекам;
6. собирает пакет в `dist/`.

Результат: `dist/trrispo25_<version>_<arch>.deb`.

## Установка

```bash
sudo apt install ./dist/trrispo25_0.1.0_amd64.deb
```

Зависимости (в частности, `libzstd1`) устанавливаются автоматически через `apt`.
Проверить, что установлено:

```bash
dpkg -l trrispo25
ldd /usr/bin/trrispo25 | grep zstd
```

Файлы после установки:

- `/usr/bin/trrispo25` — исполняемый файл;
- `/etc/trrispo25/trrispo25.conf` — конфигурация (объявлена в `DEBIAN/conffiles`,
  поэтому правки администратора сохраняются при обновлении и при `apt remove`,
  а удаляются только при `apt purge`);
- `/usr/share/doc/trrispo25/copyright`, `/usr/share/doc/trrispo25/changelog.gz` —
  документация.

### Удаление

```bash
# удалить программу, сохранив конфигурацию
sudo apt remove trrispo25

# удалить и конфигурацию
sudo apt purge trrispo25
```

## Запуск

### Справка и версия

```bash
trrispo25 --help
trrispo25 --version
```

### Сжатие файла на заданном уровне

```bash
trrispo25 compress <file> [--level N] [--output <path>]
```

- `--level N` — уровень сжатия zstd (1..`ZSTD_maxCLevel()`, обычно 22).
  Если ключ не указан, уровень берётся из `/etc/trrispo25/trrispo25.conf`
  (по умолчанию `3`).
- `--output <path>` — путь к выходному файлу. По умолчанию `<file>.zst`.


### Коды возврата

- `0` — успех;
- ненулевой код — ошибка (нет файла, некорректный уровень, ошибка
  чтения/записи и т. п.). Сообщения об ошибках выводятся в `stderr`,
  а не в `stdout`.
